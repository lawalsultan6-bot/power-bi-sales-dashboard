# power-bi-sales-dashboard
Interactive sales performance dashboard built with Power BI to analyze revenue, profit, customers and product performance.
The objective is to identify trends in sales, revenue, profit and customer performance.
Tools Used
Microsoft Excel
Power Query
Power BI
DAX
Process
Collected the dataset
Cleaned the data using Power Query
Created calculated columns/measures
Built relationships between tables
Created the Power BI dashboard
Analyzed key business insights
